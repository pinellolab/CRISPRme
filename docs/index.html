CRISPRme is now CRISPRme+

This version of CRISPRme is deprecated and no longer maintained. Active maintenance and development have moved to CRISPRme+, which adds important improvements and bug fixes, including:

  • a new phased HGDP + 1000 Genomes default variant index (4,091 samples) with confirmed-cis carriers;
  • the CRISPR-Bulge machine-learning off-target scorer (alongside CFD);
  • SNP/indel co-occurrence detection on real haplotypes;
  • numerous correctness, reporting, and usability fixes.

Please use CRISPRme+ from now on:
