Run CRISPRme on your own machine

CRISPRme is open source and actively maintained, and you can run the web interface locally on your own machine with the same functionality as before. The previous hosted application at crisprme.di.univr.it is no longer available, because institutional hosting at the University of Verona ended for this service. All features remain available to you.

The easiest way to get the same point-and-click experience is the Docker quickstart below — a few commands to a web interface running in your browser, with all the functionality of the previous hosted version. Prefer the command line for scripted or batch analyses? That works too.

Quickstart — the web interface in Docker

The simplest way to run CRISPRme is with Docker: the only thing you install is Docker itself — no conda, no compiling, and no giant download. Copy the commands below, open your browser, fill in a short form, and read your results.

1 — Install Docker

Install Docker for macOS, Windows, or Linux, and give it at least 16 GB of memory (Docker Desktop → Settings → Resources). Then check it works: 

docker run --rm hello-world

2 — Download the data and a ready-made index (minutes, not hours)

Make a folder to hold everything, then fetch the reference data and a prebuilt SpCas9 (NGG) index from the CRISPRme mirror. This replaces the old multi-hour setup and the long index build. 

mkdir -p ~/crisprme && cd ~/crisprme

# reference genome, annotations, PAMs and sample lists
docker run --rm -v "${PWD}:/DATA" -w /DATA pinellolab/crisprme \
  crisprme.py download --what all --path /DATA

# a ready-made SpCas9 (NGG) index — skips a long index build
docker run --rm -v "${PWD}:/DATA" -w /DATA pinellolab/crisprme \
  crisprme.py download --what index --index-name NGG_2_hg38 --path /DATA

Want variant-aware searches (CRISPRme's speciality)? Also run … crisprme.py download --what vcf --dataset 1000G --path /DATA to add the 1000 Genomes variants. You can skip this for a first run.

3 — Launch the web interface

docker run --rm -v "${PWD}:/DATA" -w /DATA -p 8080:8080 -it \
  pinellolab/crisprme crisprme.py web-interface

Leave that running, then open http://127.0.0.1:8080 in your browser (Chrome, Firefox or Safari). Enter a guide sequence, pick the PAM and genome, set mismatches and bulges, and click Submit. Your results are saved on your own computer under ~/crisprme/Results/. To stop the server, press Ctrl⁠+⁠C.

Nothing in the dropdowns? You skipped step 2 — run the two download commands first. Need a different nuclease? Download its index the same way (e.g. --index-name TTTV_2_hg38 for Cas12a); anything not yet published is built automatically on first use.

Other ways to install (Conda/Mamba, or build everything from scratch)

Install with Conda / Mamba

# Configure Bioconda channels (one-time)
mamba config --add channels bioconda
mamba config --add channels conda-forge
mamba config --set channel_priority strict

# Create and activate the environment, then verify
mamba create -n crisprme python=3.8 crisprme -y
mamba activate crisprme
crisprme.py --version

Then fetch data the fast way just like the Docker path (crisprme.py download --what all --path "$PWD") and launch the interface with crisprme.py web-interface.

Build the full reference database from the original sources

Instead of the fast download, you can download and configure everything (hg38, 1000 Genomes, HGDP, annotations, PAMs) directly from the original sources with the built-in setup. This is a large, multi-hour, ~410 GB one-time download; the fast download above is recommended for most users. 

# Docker
docker run -v ${PWD}:/DATA -w /DATA -i pinellolab/crisprme \
  crisprme.py setup --path /DATA

# ...or test on a single chromosome first
docker run -v ${PWD}:/DATA -w /DATA -i pinellolab/crisprme \
  crisprme.py setup --chrom chr22 --path /DATA

The web interface must be started from a working directory that contains the CRISPRme folders (Genomes/, PAMs/, Annotations/, …). The download and setup commands create these for you.
